# Deprecated Installation Scripts

The files in this directory belong to the previous MMC installation process and are retained temporarily for reference.

They are **deprecated and should not be used for new installations**.

Current MMC releases provide pre-built packages for supported operating systems. These packages include the required runtime and dependencies, so end users no longer need to install Node.js, npm or Git or run MMC directly from a source checkout.

See [INSTALLATION.md](../../INSTALLATION.md) for the current installation instructions.

These legacy files may be removed in a future release.
